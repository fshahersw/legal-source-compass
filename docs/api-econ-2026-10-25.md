# Economic and federal-spending data for litigation (api-econ, wave 1025)

Official rate, price, wage, mortality and spending series, published as corpus datasets, with litigation calculators
built on them (`/law/calculators`) and a self-updating FRED source (`supabase/functions/ingest-fred`).

FRED series (fredSpec.ts): WGS1YR (the § 1961 rate); daily Treasury constant maturities 1-month to 30-year (DGS*) and
their monthly averages (GS*); DPRIME, MPRIME, DFF, FEDFUNDS, TB3MS; CPI-U all items NSA/SA, medical care NSA/SA, medical
care services NSA/SA, CPI-W, core CPI, PCE price index; ECI wages and salaries (private and civilian, SA and NSA), ECI
total compensation; average hourly earnings (CES, AHETPI); unemployment rate (national SA/NSA and every state, DC and
Puerto Rico, SA). Third-party series (Moody's, ICE) are excluded: FRED marks them "Copyright" in their notes and the
builders refuse any series that carries it.

## Methods and checks

* **Vintages.** Observations are read with their full ALFRED real-time history; each date keeps the current value, the
  date ALFRED first shows that value, and — where a later revision changed it — the first published value and its date
  (e.g. BLS's October 2016 corrections of May–August 2016 CPI-U). FRED's "." is kept as no value (October 2025 CPI and
  unemployment were not published: lapse in appropriations). FRED serves at most 2,000 vintage dates per request; long
  histories are read in windows and merged.
* **§ 1961 rate week.** The weekly average for the week ending Friday applies to judgments entered the following Monday
  to Sunday (the district courts' uscourts.gov tables). `crosscheck_pji.py` compares every row of the District of New
  Mexico tables 2010–2026 (value and effective window) and the District of Utah correction table (2016–2019) with the
  stored series. Courts differ for a judgment entered on the release day (D. Utah applies the previous week); the
  calculator shows that difference with both rates.
* **Life tables.** Every age row of all 120 tables, rounded as the report prints it, equals the NVSR PDF text (12,120
  rows; one printed T(0) differs by 1 from the workbook in 2022 Table 2, recorded in the summary).
* **OEWS.** All 9,999 national values compared equal BLS's own May 2025 national workbook (special values `*`/`-` aside);
  broad SOC groups are not in the bulk file. **CPI by area**: BLS CUUR0000SA0 equals FRED CPIAUCNS for every month both
  hold.
* **AWI.** Each index is the sentence SSA published ("The national average wage index for 2024 is $69,846.57"); the next
  notice's restated base is checked; SSA's corrections of 2009 and 2016 are kept as superseded values.
* **Federal awards.** Exact UEI only: a SAM exclusion record's UEI equals the USAspending recipient's UEI. SEC companies
  are linked only through `scripts/api_econ/company_identifier_crosswalk.json` (official records stating both CIK and
  UEI/DUNS; empty — SEC and USAspending publish no common identifier). No name matching.
* **State rates.** Only rates an official statute or agency page states, quoted and checked against the captured page;
  every other state shows "Not recorded". California, New York and New Jersey pages answered HTTP 403 and Illinois'
  certificate did not verify; they were not used.

## Calculators (`/law/calculators`)

Six in-page tabs: post-judgment interest (28 U.S.C. § 1961: rate lookup by judgment date, daily accrual, annual
compounding, 365-day or actual-day basis), inflation (CPI-U and four other indexes, any two months), present value
(Treasury maturity and date as the discount rate, annual or bond-equivalent treatment), life expectancy (NCHS table year,
sex, race and Hispanic origin), state rates, sources. Pure functions in `src/lib/calculators` with hand-verified golden
tests; every result lists its inputs, the published values (series, date, value, vintage, URL) and the method.

## RUNBOOK (lead)

All commands from the repository root. Keys load from `private/scratch/secrets.env` inside each process and are never
printed. Builders write `private/build/w1025_api-econ/<area>/<dataset>.json` in the enrichment contract format.

1. FRED full build (~99 series, ~350 requests 0.6 s apart, 15–20 min, ~30 MB build files):
   `node scripts/api_econ/fred_build.mjs` → `private/build/w1025_api-econ/fred/econ_fred_series.json`,
   `econ_fred_observations.json`, `manifest.json`.
   Cross-check: `python3 -I -B scripts/api_econ/crosscheck_pji.py` (17 + 1 requests).
2. NCHS: `python3 -I -B scripts/api_econ/build_life_tables.py --acquire` (120 files, 3 MB, 3 min), then
   `python3 -I -B scripts/api_econ/verify_life_tables.py --delete-pdfs` (7 PDFs, ~10 MB transient), then
   `python3 -I -B scripts/api_econ/build_life_tables.py`.
3. SSA AWI: `python3 -I -B scripts/api_econ/build_ssa_awi.py --acquire` (35 requests) then `... build_ssa_awi.py`.
4. BLS: `python3 -I -B scripts/api_econ/build_bls.py --acquire-cpi`; `... --acquire-oews` (streams 331 MB once, keeps a
   117 MB filtered file); `curl` the national workbook `https://www.bls.gov/oes/special-requests/oesm25nat.zip` to a
   scratch folder; `python3 -I -B scripts/api_econ/build_bls.py`; `python3 -I -B scripts/api_econ/verify_bls.py --oews-zip
   <zip>`; build again (the summary picks up the verification); delete `private/acq/w1025_api-econ/bls/oe.filtered.tsv`.
5. Census CVAP: `python3 -I -B scripts/api_econ/build_census_cvap.py --acquire` (18 requests) then build.
6. State rates: `python3 -I -B scripts/api_econ/build_state_rates.py --acquire` then build.
7. USAspending (~5,700 requests 1 s apart, about 1 h 40 min; ~30 MB raw):
   `. private/scratch/env.sh && python3 -I -B scripts/api_econ/build_usaspending.py --lookup-from-corpus` (read-only),
   `python3 -I -B scripts/api_econ/build_usaspending.py --acquire`, then `... build_usaspending.py`.
8. Publish each build file: `. private/scratch/env.sh && python3 -I -B private/scratch/enrich/publish_build.py --check
   <files>` then `--publish <files>`.
9. Apply `database/contracts/api-econ-v1.sql` (after ingest-v1.sql), set the function secret `FRED_API_KEY`, deploy
   `supabase functions deploy ingest-fred --project-ref xosqzzsnhxcyehcnirpa --no-verify-jwt`, run `fred_observations` then
   `fred_series` once manually (SQL in the file header), enable both, apply the file again for the cron jobs.
10. Apply `database/contracts/insights-economy-v1.sql` (after insights-v1.sql), then `select insights.refresh_entities('initial');
    select insights.refresh_economy('initial');`.

Verification SQL:

```sql
select id, ready, imported_records from public.corpus_datasets
 where id in ('econ_fred_series','econ_fred_observations','econ_nchs_life_tables','econ_ssa_awi','econ_bls_cpi_areas',
              'econ_bls_oews','census_acs_cvap_counties','econ_state_judgment_rates','company_federal_awards') order by id;
-- § 1961 rate for judgments entered 2026-10-12..18 is 4.45 (uscourts.gov district tables)
select o from public.corpus_records r, jsonb_array_elements(r.item->'fred'->'obs') o
 where r.dataset = 'econ_fred_observations' and r.id = 'fred:WGS1YR:2026' and o->>0 = '2026-10-09';
-- CPI-U January 2024 = 308.417; October 2025 not published (null)
select o from public.corpus_records r, jsonb_array_elements(r.item->'fred'->'obs') o
 where r.dataset = 'econ_fred_observations' and r.id in ('fred:CPIAUCNS:2024','fred:CPIAUCNS:2025') and o->>0 in ('2024-01-01','2025-10-01');
select item->'cells'->>'e0' from public.corpus_records where dataset = 'econ_nchs_life_tables' and id = 'nchs-lt:2024:01'; -- 79.0
select item->'awi'->>'value' from public.corpus_records where dataset = 'econ_ssa_awi' and id = 'awi:2024';           -- 69,846.57
select source, status, fetched, inserted, updated, unchanged, error from ingest.runs
 where source in ('fred_observations','fred_series') order by started_at desc limit 6;
select metric_id, count(*), min(period), max(period) from insights.facts where metric_id like 'econ_%' group by 1 order by 1;
```
