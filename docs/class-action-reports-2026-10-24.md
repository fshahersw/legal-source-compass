## How facts were extracted

Facts are read from the PDF text layer: printed tables (every row must fit the table's columns; a table with a Total row must add up to it or is held) and strict sentence patterns in the prose. Values printed only inside charts are not used. Dollar values keep the basis the report states (e.g. inflation-adjusted to 2025 dollars); 'not stated' where the report states none. Values restated in later reports are kept per report vintage.
