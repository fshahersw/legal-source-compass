# Timeline document resolution — October 5, 2026

Commit `e55034e` adds server-side exact source/document-ID lookups for documents explicitly listed on timeline entries. It calls the existing `corpus_pdf_documents_by_id_v1` RPC in batches of at most 500, requires a matching source and ID from the active batch, and checks the returned native case ID against the entry's recorded docket relationship. Exact rows replace cached copies before hash deduplication, preserving fresh held/open status. Held rows remain unlinked and disclose no hash or byte count.

The broad matter archive still has its 20,000-row cap. Its completeness flag remains authoritative: when that list is partial, unmatched DocketBird case-plus-entry supplements remain unverified and are not presented as absent. The shared source mapping is exported from `timeline.ts` and reused by the server lookup.
