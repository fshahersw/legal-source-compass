`scripts/ingest/upload-original-metadata-to-supabase.mjs` defaults to dry validation. Execution requires the explicit `--execute` flag, a private server credential file, a matching plan SHA, correct project, service credential, and a bucket whose observed `public` setting is exactly false. It reads no credential from process environment. Storage paths use `seeger-weiss/metadata-sha256/<first-two-hash-characters>/<sha256>.json`. Uploads use no overwrite and at most eight workers; every object remains bounded to 6 MiB.

The worker verifies a complete authenticated cloud GET before recording success, including exact SHA-256, size, UTF-8 and JSON. An unknown upload response is checked independently before the single permitted upload retry. A cloud GET interrupted by an explicitly classified network failure, timeout or transient server response has at most three whole-read attempts, with one- and two-second waits. Each attempt uses a fresh response and fresh digest; partial reads are discarded. Hash/size/JSON/UTF-8 failures, TLS certificate failures, authentication failures and throttles never use this retry path. HTTP 400/409 never proves an existing object without readback; only an explicit missing-object code allows creation after a 400 GET. Resume rechecks cloud bytes rather than trusting an old receipt. Upload response bodies are consumed within a 64 KiB limit to allow connection reuse. Per-source receipts are appended and fsynced outside Git, with sanitized failure codes, allowlisted error types and cause codes; URLs and exception messages are excluded. Local source files remain intact.

The default object host remains the verified project origin. Root may explicitly select `--object-host=direct`, which derives only `https://xosqzzsnhxcyehcnirpa.storage.supabase.co`; arbitrary hostnames and host fallback are unavailable. The bucket-private guard remains on the correct project origin. Supabase documents the [direct storage hostname](https://supabase.com/docs/guides/storage/uploads/resumable-uploads) and recommends [standard uploads for small files](https://supabase.com/docs/guides/storage/uploads/standard-uploads).
