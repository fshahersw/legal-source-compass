These are in `land_publisher_code_v2.py`:
- Storage readback is streamed (running sha256, byte and UTF-8 code-point counts), so a large original is never held in memory.
- New `--checkpoint`:
  - verified batches are saved to a checkpoint file and skipped on restart;
  - an exact batch that already landed (the "already observed" error) is verified instead of being sent again;
  - when the run fails, it is left open so it can resume, instead of being closed as failed.
