# Legal Source Compass

Create a NEW, UNPUBLISHED project named Legal Source Atlas. Do not modify any existing project or deploy publicly. Build the approved first version of a compact premium searchable U.S. litigation source directory, not a chatbot. White sidebar, restrained navy/gray, excellent typography, high-quality compact source table, breadcrumbs, filters, right-hand detail drawer. Views: Library, Jurisdictions, Source Families, Endpoint Explorer, Review Queue, Saved Sources, Data & Exports. Use real supplied V2.2A data only. Source bundle will be attached once upload permission is available: it contains 4,633 exact distinct source URLs from 6,372 original occurrences, 258 raw endpoint candidates, eight source families and 73 imported promotion records, with original files and provenance. Do not invent or fabricate records or hardcode those counts as live data. Until the bundle is attached, show an honest empty import state and implement JSON bundle import. Preserve original URLs including queries and hash routes. Keep raw imported source fields immutable; imported authority/currentness/review labels are not fresh verification. Search actual titles/URLs/domains/heading categories/jurisdictions; pagination; working source details, copy URL, open external URL, bookmark and CSV/JSON exports. Review actions are browser-local overlays with required reasons, timestamps and Undo, separate from imported curation. Label browser-local persistence clearly. No paid external services, Cloud database provisioning, API keys, live crawling, analytics, fake verification, fake metrics, or public deployment. Keep project workspace-private. Implement with the normal TypeScript/Tailwind/shadcn stack, write data/filter/review/export tests and run a production build. Report actual results and limitations. This is the first version; Tavily server-side harvesting comes later.
